# BridgeAdminAccessControl

A Bridge extension (extension contract 0.1): per-role access control to the page tree, its
subtrees and the four core top-level admin menus. See `docs/access-control.md` in Bridge.

Generated by `php tools/scaffold-extension.php BridgeAdminAccessControl`, then shaped.

- Slots: none
- Client module: none
- Theme surface: the hookable `navCacheKey`, only when AdminThemeBridge 0.28.0 or later is installed

## Install

Copy (or junction) the directory to `site/modules/BridgeAdminAccessControl/`, then Modules > Refresh and install
it. It does not require AdminThemeBridge. Without rules nothing changes.

## Contract tests

From a Bridge checkout, against a sandbox (`tools/sandbox-site.sh`) with the module under
`app/modules/BridgeAdminAccessControl/`:

```
php tools/extension-check.php sandbox/<site> BridgeAdminAccessControl
node tools/extension-check.js <path to playwright-core> chromium BridgeAdminAccessControl
php tools/extension-compat.php
```

`BridgeAdminAccessControl.check.php` holds the extension's own checks; `extension-check.php` runs it.

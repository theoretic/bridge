# BridgeSample

A Bridge extension (extension contract 0.1): a ProcessWire module that uses the published
surface of the admin theme AdminThemeBridge. See `docs/extensions.md` in Bridge.

Generated by `php tools/scaffold-extension.php BridgeSample --slots=masthead-right,user-nav,content-head-buttons,footer,drawer,body --module`.

- Slots: `masthead-right`, `user-nav`, `content-head-buttons`, `footer`, `drawer`, `body`
- Client module:`BridgeSample.mjs` (defines `<pw-bridgesample>`)

## Install

Copy (or junction) the directory to `site/modules/BridgeSample/`, then Modules > Refresh and install
it. It requires AdminThemeBridge. The slots show for signed-in users whose admin theme is Bridge.

## Contract tests

From a Bridge checkout, against a sandbox (`tools/sandbox-site.sh`) with the module under
`app/modules/BridgeSample/`:

```
php tools/extension-check.php sandbox/<site> BridgeSample
node tools/extension-check.js <path to playwright-core> chromium BridgeSample
php tools/extension-compat.php
```

`BridgeSample.check.php` holds the extension's own checks; `extension-check.php` runs it.

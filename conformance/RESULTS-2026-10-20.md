## Script warnings, by script

- `RockMigrations/RockMigrations.js`, davinci, 115 screens. It is added on every admin page at
  init and deferred on purpose: printed without jQuery it throws (milestone 3.2). It runs
  wherever the stack loads.
- `Fluency/assets/bundle/scripts/fluency.js`, testfly 62 and txm 69 screens. It is the same
  admin-wide pattern, but its job is visible: translation buttons on multi-language fields. On
  native page editors they do not appear unless the stack loads. Open: decide whether Fluency is a
  legacy reason where multi-language fields render, or gets a native stand-in.
- One screen each, the module's own config screen (ProcessModule is native): `AdminOnSteroids`
  (`aos_config.min.js`, davinci), `ProcessGeneralSettings/Settings.js` (ofsla, paraavis),
  `ProcessHannaCode.js` (testfly). Open: check why these were deferred and not recorded as
  `Script:` reasons; they may be registered before the Process runs, which leaves them deferred
  by design.

## Notes on 0.9.1

The native map now takes wrappers by exact class. `InputfieldSeoNeoPreview extends
InputfieldMarkup`, on seven sites, is therefore legacy where it renders; before, it counted as
native by inheritance. No screen differs because of it. Under Bridge those screens now load the
stack, as they would have needed to for SeoNeo's script anyway. `nativeOverrides` can switch it
back (`InputfieldSeoNeoPreview=native`).

## After 0.9.3 (2026-10-21)

The open script warnings above are fixed (CHANGELOG 0.9.3). `bash tools/gate1.sh` on the five
sandboxes that had them, each with 0 differ and 0 failed:

| Sandbox | Script warnings before | After |
|---|---:|---:|
| davinci | 116 | 113 (RockMigrations only) |
| ofsla | 1 | 0 |
| paraavis | 1 | 0 |
| testfly | 63 | 0 |
| txm | 69 | 0 |

- Fluency: the `scriptNeeds()` map prints `fluency.js` where no multi-language field renders and
  makes it a legacy reason (`Script:Fluency/fluency.js`) where one does. Page editors of
  multi-language sites with Fluency therefore load the stack (testfly: 70 of 125 screens legacy).
- AdminOnSteroids, GeneralSettings: added at ready or init on their own config screen, before the
  Process; a module's jQuery script from its own directory is now a reason on its config screen.
  On davinci this also loads the stack on RockMigrations' own config screen.
- ProcessHannaCode: its `execute()` throws on testfly (under Uikit too), so the after hook never
  recorded `Process:ProcessHannaCode`; `settleProcess()` (default.php) now does.
